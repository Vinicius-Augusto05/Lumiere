## 5. Máquina virtual e banco de dados

**Período:** Novembro de 2026

**Objetivo da utilização da IA:** Configurar o banco de dados MySQL em uma máquina virtual Linux, conforme os requisitos da disciplina.

**Solicitações realizadas:**
- Orientação para instalação do MySQL Server no Ubuntu.
- Configuração de usuário e permissões.
- Exportação e importação do banco de dados.
- Configuração da pasta compartilhada entre o computador e a VM.
- Configuração do encaminhamento de portas no VirtualBox.
- Configuração da conexão do Node.js com o banco da máquina virtual.

**Como a IA auxiliou:** Forneceu orientações passo a passo, explicou comandos do terminal e ajudou a diagnosticar erros durante a configuração.

**Resultado:** O banco Lumière foi importado para a VM e a aplicação Node.js passou a consultar os dados armazenados nela.

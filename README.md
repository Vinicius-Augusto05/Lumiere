# Lumiere
Projeto individual SPTECH - VIDEOGAME SÃO PARA TODOS

> Talvez exista um jogo que também faça parte da sua história.

## Sobre o projeto

Lumière é um projeto individual desenvolvido na SPTech School, com a proposta de mostrar que os videogames são para todos e arte.

O projeto nasce da minha relação pessoal com os jogos e da vontade de compartilhar como eles podem representar muito mais do que entretenimento: podem criar memórias, despertar sentimentos, aproximar pessoas e fazer parte da história de alguém.

## Objetivo

Apresentar minha trajetória com os videogames e permitir que visitantes descubram qual estilo de jogador mais combina com sua personalidade, mesmo que nunca tenham tido muito contato com jogos.

## Funcionalidades planejadas

- **Minha história:** uma experiência interativa sobre minha trajetória com os videogames.
- **Universo dos jogos:** conteúdos sobre o que torna os videogames especiais.
- **Quiz de personalidade:** perguntas para descobrir o estilo de jogador do visitante.
- **Dashboard:** apresentação dos resultados, distribuição dos estilos e histórico de testes.
- **Conta de usuário:** cadastro e login para acessar o quiz e os resultados pessoais.

## Tecnologias previstas

- HTML
- CSS
- JavaScript
- Node.js
- MySQL

As tecnologias e funcionalidades serão desenvolvidas conforme os conteúdos estudados durante o semestre.

## Desenvolvimento

Este projeto está em fase de planejamento e desenvolvimento. O repositório será atualizado durante sua construção, registrando a evolução do código e os conhecimentos aplicados.

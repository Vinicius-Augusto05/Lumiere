# Requisitos do Projeto — Lumière 🏮

## 1. Requisitos funcionais

Os requisitos funcionais descrevem as funcionalidades que o sistema deverá oferecer.

| Código | Requisito |
|---|---|
| RF01 | O sistema deverá apresentar uma página inicial com informações sobre o Lumière. |
| RF02 | O sistema deverá permitir que visitantes acessem os conteúdos públicos sem cadastro. |
| RF03 | O sistema deverá apresentar a trajetória pessoal do autor com os videogames. |
| RF04 | O sistema deverá permitir o cadastro de novos usuários. |
| RF05 | O sistema deverá permitir que usuários cadastrados realizem login. |
| RF06 | O sistema deverá disponibilizar um questionário sobre personalidade e estilos de jogadores. |
| RF07 | O sistema deverá registrar as respostas de cada tentativa do questionário. |
| RF08 | O sistema deverá calcular a pontuação dos seis estilos de jogadores. |
| RF09 | O sistema deverá apresentar a distribuição das pontuações e destacar os dois estilos com maior pontuação. |
| RF10 | O sistema deverá apresentar um gráfico com a distribuição dos resultados. |
| RF11 | O sistema deverá recomendar jogos relacionados aos dois estilos com maior pontuação, apresentando dois jogos para cada estilo. |
| RF12 | O sistema deverá armazenar as tentativas e respostas dos usuários no banco de dados. |
| RF13 | O sistema deverá solicitar cadastro ou login para que o visitante possa realizar o questionário e acessar a dashboard. |

## 2. Requisitos não funcionais

Os requisitos não funcionais descrevem características de qualidade, segurança e funcionamento do sistema.

| Código | Requisito |
|---|---|
| RNF01 | O sistema deverá possuir uma interface intuitiva e de fácil utilização. |
| RNF02 | O site deverá apresentar identidade visual consistente com a proposta do Lumière. |
| RNF03 | O sistema deverá armazenar as senhas utilizando hash, evitando seu armazenamento em texto puro. |
| RNF04 | A comunicação entre frontend e backend deverá ocorrer por meio de uma API. |
| RNF05 | O banco de dados deverá utilizar MySQL. |
| RNF06 | O sistema deverá apresentar resultados de maneira organizada e compreensível. |
| RNF07 | O site deverá ser desenvolvido para funcionar nos principais navegadores modernos. |
| RNF08 | O código deverá ser organizado em arquivos e camadas para facilitar sua compreensão e manutenção. |

## 3. Observação

Os requisitos foram definidos considerando a proposta inicial do Lumière e ajustados conforme as funcionalidades efetivamente desenvolvidas e testadas durante o projeto.

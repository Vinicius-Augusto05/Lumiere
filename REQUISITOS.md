# Requisitos do Projeto — Lumière 🏮

## 1. Requisitos funcionais

Os requisitos funcionais descrevem o que o sistema deverá fazer.

| Código | Requisito |
|---|---|
| RF01 | O sistema deverá apresentar uma página inicial com informações sobre o Lumière. |
| RF02 | O sistema deverá permitir que visitantes acessem os conteúdos públicos sem cadastro. |
| RF03 | O sistema deverá apresentar a trajetória pessoal do autor com os videogames. |
| RF04 | O sistema deverá permitir o cadastro de novos usuários. |
| RF05 | O sistema deverá permitir que usuários cadastrados realizem login. |
| RF06 | O sistema deverá disponibilizar um quiz sobre estilos de jogadores. |
| RF07 | O sistema deverá registrar as respostas de cada tentativa do quiz. |
| RF08 | O sistema deverá calcular a pontuação dos seis estilos de jogadores. |
| RF09 | O sistema deverá apresentar o estilo predominante do usuário. |
| RF10 | O sistema deverá apresentar gráficos com a distribuição dos resultados. |
| RF11 | O sistema deverá apresentar recomendações de jogos relacionadas ao resultado. |
| RF12 | O sistema deverá armazenar o histórico de tentativas do usuário. |
| RF13 | O sistema deverá permitir a consulta de resultados anteriores. |
| RF14 | O sistema deverá restringir o acesso ao dashboard e aos resultados aos usuários autenticados. |

## 2. Requisitos não funcionais

Os requisitos não funcionais descrevem características de qualidade, segurança e funcionamento do sistema.

| Código | Requisito |
|---|---|
| RNF01 | O sistema deverá possuir uma interface intuitiva e de fácil utilização. |
| RNF02 | O site deverá apresentar identidade visual consistente com a proposta do Lumière. |
| RNF03 | O sistema deverá armazenar as senhas de forma protegida, utilizando hash. |
| RNF04 | A comunicação entre frontend e backend deverá ocorrer por meio de uma API. |
| RNF05 | O banco de dados deverá utilizar MySQL. |
| RNF06 | O sistema deverá apresentar resultados de maneira organizada e compreensível. |
| RNF07 | O site deverá funcionar nos principais navegadores modernos. |
| RNF08 | O código deverá ser organizado e documentado para facilitar sua manutenção. |

## 3. Observação

Os requisitos poderão ser revisados durante o desenvolvimento, conforme as orientações dos professores e as necessidades identificadas nos testes.
